# Going FORTH
## Building a small interactive language

This section was inspired by
[jonesforth](https://rwmj.wordpress.com/2010/08/07/jonesforth-git-repository/),
an excellent tutorial on writing a FORTH interpreter in x86 assebly.

Here we will create our own FORTH interpreter. The FORTH language is an unusual
one, more powerful than it appears at first, but extremely minimalist.
